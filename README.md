# Expense Tracker System

## 📌 Description
The Expense Tracker System is a web-based application designed to help users manage and track their daily expenses efficiently. It allows users to record expenses, categorize them, and analyze spending patterns.

## 🚀 Features
- Add and manage daily expenses
- Category-based expense tracking
- Budget control and alerts
- Time-based analysis (daily, monthly)
- Graphical reports
- Group expense management
- Real-time updates

## 🛠️ Technologies Used
